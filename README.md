# Daniel Prost

System Administrator focused on **infrastructure, automation and reliable operations**.

I work with Linux and Windows environments and enjoy building systems that are practical, maintainable and recoverable. A lot of my spare-time engineering happens in a real self-hosted environment, where I can test operational ideas before deciding whether they are worth keeping or generalizing.

## Focus areas

- Linux & Windows Server
- Ansible & Infrastructure as Code
- Docker & containerized workloads
- Git & GitHub Actions
- Monitoring, backup & recovery
- Deployment safety and rollback

## Projects

### [DeployInvariant](https://github.com/d-prost/deploy-invariant)

A lightweight Git + Ansible transaction layer for Docker Compose. It focuses on explicit deployment invariants: target identity, immutable inputs, functional verification, durable acceptance, interruption recovery and verified rollback.

### [HomeLab Engineering](https://github.com/d-prost/homelab-engineering)

Architecture decisions, experiments, incident lessons and recovery reasoning from a real self-hosted environment, rewritten as a public engineering record rather than a live infrastructure mirror.
